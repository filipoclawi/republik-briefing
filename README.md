# Republik Briefing

Weekly, lightly filtered previews of unread newsletters from the exact Gmail label `Republik`.

Planned public URL: <https://filipoclawi.github.io/republik-briefing/>

- Saturday–Friday editions with navigation across the archive
- One concise German preview per newsletter title
- Clean direct links to each original publication (chiefly `republik.ch`)
- Rough reading-time estimate before every click
- No email addresses, Gmail identifiers, tracking redirects, recipient data or private attribution

Run local verification with `python3 tests/ui_smoke.py`.
